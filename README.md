# pixel-dash
Voilà Pixel Dash, un runner complet : saut / double saut au toucher ou au clavier, pièces à ramasser, vitesse progressive, menu, écran de règles, pause automatique si l'app passe en arrière-plan, sons synthétisés (aucun fichier externe) et record sauvegardé sur l'appareil. Il s'adapte à toute taille d'écran, donc ordi et mobile.
